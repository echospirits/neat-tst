# AI abstraction

Date: 2026-10-10. Status: accepted implementation direction, except explicitly proposed items.

## Context

Extend the existing multi-tenant Neat application without changing the meaning of established records or authorizing production.

## Decision

Require permission-filtered source retrieval and attributed suggestions. No automated outbound correspondence. Status: common service proposed.

## Alternatives and trade-offs

A mandatory AI dependency would prevent deterministic/manual workflows when credentials or the provider are unavailable.
