# SMS architecture

Date: 2026-10-10. Status: accepted implementation direction, except explicitly proposed items.

## Context

Extend the existing multi-tenant Neat application without changing the meaning of established records or authorizing production.

## Decision

Use an interchangeable SMS provider with consent and opt-out checks, signed webhooks and provider-event idempotency. Mock mode cannot send live traffic. Status: proposed, not implemented.

## Alternatives and trade-offs

Personal-device scraping and uncontrolled sender identities are excluded. Twilio is the first candidate, not an implicit live subscription.
