# Product principles

Audit baseline: TST `5faee9df930bd76b5e56b669f58a57210527f7d5`, inspected 2026-10-10.

Prioritize outcomes over raw activity counts. Support human judgment with transparent recommendations and source evidence. Preserve account and return context. Unknown data is not zero. Separate placement commitments from verified placement, first orders from sustained purchasing, and physical visits from other contact. Do not build the CFAO analysis engine; manual analytical tags remain supported.
