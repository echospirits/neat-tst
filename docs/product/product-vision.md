# Product vision

Audit baseline: TST `5faee9df930bd76b5e56b669f58a57210527f7d5`, inspected 2026-10-10.

Neat (Echo CRM / OHLQ Field CRM) is a daily sales operating system for beverage suppliers. Help representatives build durable customer relationships, develop accounts, complete commitments and improve retention. Echo Spirits is the initial tenant, not a hardcoded platform identity. Capture evidence automatically where practical and request manual input where it adds value.
