## Responsive and interaction evidence

- `scripts/ui-upgrade-browser.ts` renders 13 actual component/page scenes with synthetic records and inert actions. Final acceptance covers 78 scene/viewport/theme combinations at 390 x 844, 1440 x 900 and the observed in-app size 742 x 668, in light and dark themes. No horizontal page overflow, browser runtime errors or undersized checked mobile controls were found. The check includes visible populated events, immediate demand, one product destination per product, and Pipeline's imported list styling.
- Separate 320px reflow and 200% root-text checks pass for Pipeline, Forecast, Log Visit and Users in both themes. They are representative accessibility checks, not complete WCAG certification.
- Actual hydrated `ActivityTimelineFilter` and `RecordPicker` acceptance verifies five picker resets, two date resets, three records restored, successful reselection and Escape returning focus to the trigger. This goes beyond static HTML rendering.
- Saved account/profile/plan facts, task context and material failures remain readable without opening editing menus. Source-derived disclosure counts in the audit distinguish these changes from measured human task speed.
- Matched baseline/working-source screenshots and JSON are under ignored `output/playwright/ui-upgrade-20261104/first` and `final`. A missing fixture import of the existing `salesStatus.css` initially produced false Pipeline list markers; the harness now includes that component stylesheet and explicitly checks its list styles. Early affected Pipeline images are superseded by corrected captures, not evidence of a production defect.
- Mechanical Impeccable detection ran once. It reported three legacy side-border warnings: one is a disclosure-triangle false positive, superseded by the shared chevron; two old callout/timeline rules were reduced to 1px. The scan was not rerun and is not described as zero findings.
- Independent behavioral review found three introduced issues: stale picker selections after reset, paused calendar sync mislabeled as failure, and a lost mobile phone target. All three are fixed and scored resolved; actual calendar errors versus neutral DISABLED/REMOVED/PENDING messages have four component regression cases.
- The fresh finish review requested enlarged Forecast reflow/sort visibility, corrected Pipeline fixture styling and persisted direction provenance. Its verdict scores all three listed fixes resolved, with disposition **ship for that fix list**. This does not imply unbounded whole-app or human acceptance.
