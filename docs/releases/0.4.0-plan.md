Stable candidate version: `0.4.0`; scope is limited to that removal, dependency cleanup and relevant validation/documentation. No unrelated development is authorized.

- Production `origin/main`: `438b1ae1`, released 0.3.0 (`191e4843`). No v0.3.0 tag exists in the verified remote.

## Scope and safeguards

Remove the Communications destination, OAuth/sync/cron, business SMS, contact suggestions and reviewed communication assistant. Preserve ordinary account/contact/manual-interaction workflows, history, Worklist/calendar, events and Pipeline. Keep the schema/migration ledger compatible; no migration, database deletion, provider activation or hosted configuration change is needed.

Complete the [checklist](0.4.0-checklist.md), then create a single-parent commit from current main using the exact tested candidate tree. Record exact refs/results in [validation](communications-retirement-validation.md).
