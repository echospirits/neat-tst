# Extended v0.2 development notes — 0.2.3-dev

This is a TST development increment, not the complete requested release candidate. Existing historical 0.2 artifacts are unchanged. Production remains 0.14.0 and requires separate promotion authorization.

## New

- Account relationship timeline combines manually logged interactions, imported email/meeting metadata, physical visits and completed follow-ups, with private visibility and type filtering.
- Relationship briefing separates contact, meaningful interaction, visit and follow-up dates; explains attention signals and offers contextual follow-up/visit actions.
- Deals provides tenant stages, account-linked pursuits, progress/outcomes, history and open weighted revenue estimates.
- Communications adds Google/Microsoft read-only mailbox connection infrastructure, owner-private matching review, scope/retention controls, disconnect/delete and a working nonproduction fixture mode.
- Permanent product/architecture/design/engineering documentation, ADRs, migration/setup guides and repeatable database/browser regression scripts.

## Improved

- Next.js 16.3.8 and compatible dependency security updates.
- Existing account activity sections preserve initiated-action semantics and exclude another user's private imported correspondence.
- Account links and shared form controls preserve context and input after errors.

## Configuration and known limits

Live providers require credentials, user consent and provider acceptance; none was established by fixture tests. No integrated SMS, outbound mail, body/attachment ingestion or communication AI is shipped. The broader brief still lacks contact graph, configurable health/playbooks, generalized territories/accounts, recipe sales tools, event operations/attribution and expanded reporting.
