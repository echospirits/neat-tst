# Neat 0.3.0 release notes

Prepared for the frozen candidate; not yet released to production.

## New

- Production Forecasting in Analytics: next-30-day outbound case estimates, ranges, confidence and planning targets, with product, week and fulfillment-location context.
- Ohio source history and daily reconciliation support for Bailment PO/Invoice and Partner DC data. Forecasts show insufficient coverage when reliable history is unavailable.

## Improved

- Neat is focused on Echo Spirits. Echo administrators manage users, settings, imports, account maintenance and research directly.
- Current forecasts omit Distillery Only and delisted Ohio products while retaining source history and prior snapshots.

## Removed

- In-app Support, Recipes and public recipe sheets.
- Customer onboarding, company switching and platform administration. Existing outside records remain retained and isolated.

## Fixed

- Login and background jobs consistently enforce Echo membership.
- Release audits compare against the actual production version.

Production Forecasting requires its production migration, source configuration and validated initial history load. Upstream source failures remain visible. No live mail/SMS/routes/AI integration is activated by this release.
