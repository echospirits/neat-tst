## Scope

TST-only implementation dated 2026-10-11. Development stays at 0.2.3-dev within the owner-requested v0.2 package. Production baseline: af1f396726e3b15e1167f5af2aa6ba426cae9bf9. No production release or database write is authorized by this change.

- Navigation, account pages, search, visits, Worklist, Intelligence, Analytics and digest wording use Retail and Restaurants. Stable routes, model names, enum values, CSV columns and official Ohio A-3a wholesale-order terminology remain compatible.
- Platform organization creation and editing have an independent, searchable, multi-select State access section. Changes require Platform Admin and create an audit event. Plan changes do not overwrite state choices.
- Organization.enabledStates defaults to OH. Existing Echo Spirits receives OH and FL; every other existing tenant receives OH. Primary-state integration metadata does not grant account access.
- The shared Prisma client applies current authenticated-organization state filters to directories, direct IDs, counts, search, related private records, nested collections and counts, and mutations. Support View uses the selected organization. Missing HTTP authentication fails closed. Legacy blank states are treated as Ohio. Tenant predicates remain mandatory in services; state scope supplements them.
- Authenticated system cron/shared offline imports can curate shared directories. Tenant digest, calendar and mailbox dispatches, plus provisioning, explicitly enter the tenant state context. New tenant background work must use runWithOrganizationStateAccess. Raw SQL bypasses Prisma extensions: Analytics raw reads are retained-day coverage checks behind the entitled market adapter. The state resolver also reads only distinct account-reference IDs from schema-defined tables, intersecting them with allowed directory IDs to avoid large repeated SQL parameter lists; those raw IDs never reach a page.
- Florida account access does not imply Florida sales or inventory coverage. Analytics exposes only entitled markets and reports unsupported sales data as unavailable.
