# Neat 0.5.1 — Account address links

Owner-authorized hotfix, November 2, 2026. Development remains frozen.

## Fixed

Clicking a retail or wholesale account address opens that address in Google Maps location search so the user can review the location and choose whether to get directions. This applies to account details and directory address links on desktop and mobile. Explicit Directions buttons continue to open directions.

## Scope

- Shared `AddressLink` uses Google's cross-platform Maps search URL and no longer substitutes Apple Maps or Android geo links.
- Address encoding, missing-address feedback, display text, styling and safe new-tab behavior are preserved.
- Version metadata advances from 0.5.0 to 0.5.1. No dependency, migration, schema, tenant/authentication, provider, environment, feature-flag or hosted-setting change.
- Production base: `5e498ee74f70199319419c393fda9d8a1df113ab`. TST delivery base: `257bb2e27d03568fb169744a698b17f367dddb97`. TST-only test/developer-tooling maintenance and the separately delivered OHLQ stale-source warning correction are excluded from production.
- URL semantics: [Google Maps URL documentation](https://developers.google.com/maps/documentation/urls/get-started#search).
