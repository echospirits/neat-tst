# Troubleshooting

Audit baseline: TST `5faee9df930bd76b5e56b669f58a57210527f7d5`, inspected 2026-10-10.

An initiated call/email does not establish completed contact. A calendar sync success does not establish a particular event arrived: inspect provider cursor and linked event. On Windows, concurrent Prisma generation can lock query_engine-windows.dll.node; serialize test/build generation. If TST advances, fetch/rebase and preserve release entries; never force-push. OAuth reconnect is distinct from transient throttling.
